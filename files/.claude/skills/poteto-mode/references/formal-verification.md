# Bounded formal verification

When a project verify skill already covers the subject, read `maintain-formal-verification-skill/SKILL.md` in full and follow it.
Reply with its report: the outcome for each check, the commits read, the rerun and any bug.

Otherwise:

1. Read `create-formal-verification-skill/SKILL.md` in full.
2. Follow it for the requested invariant or race, including tool provenance, source mapping and a broken-variant check.
3. Keep an explicit no-verifier outcome when formal checking would not help or a pinned tool is unavailable.

**Reply.**
The property, selection reason, result, bounds, rerun command and evidence.
