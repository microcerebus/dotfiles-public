cheatsheet vim core - the grammar

Vim is a language, not a list of shortcuts: [count] verb + motion/text-object. d2w = delete two words, ci" = change inside quotes, y} = yank to end of paragraph. Learn the pieces below and every combination works.

Motions - where the cursor goes

hjklleft · down · up · right
w / b / enext word start / back / word end (WBE = space-delimited)
0 / ^ / $line start / first char / line end
fx / txjump onto / just before next "x" (FT backwards; repeat ; / reverse ,)
{ / }paragraph up / down
gg / G / 42Gfile top / bottom / line 42
%matching bracket/paren
H M Lscreen top / middle / bottom
ctrl+d/uhalf-page down / up · zz center cursor line
]f / [fnext / previous function (]F [F = function end) - treesitter
]k / [knext / previous class or interface (]K [K = end)
]i/[i · ]o/[onext / previous if/switch/try · loop (]c [c stay git hunks)

Operators - what to do

d / c / ydelete / change (delete + insert) / yank - each takes any motion
dd cc yydoubled = whole line
D Cdelete / change to end of line
x / rx / sdelete char / replace char with x / substitute char
> < =indent · outdent · auto-indent (e.g. >ip, =ap)
gu / gU / g~lowercase / uppercase / toggle case
Jjoin line below onto this one
u / ctrl+rundo / redo (persistent across sessions here)
.repeat the last change - the most underrated key in vim

Text objects - what to act on

iw / awinner word / word + space
i" i' i`inside quotes (a" includes them)
i( i[ i{ i<inside brackets (a( … includes them)
it / atinside / around an HTML/JSX tag
ip / apinner / around paragraph
if / afinner / around function (treesitter, arrow fns too)
ic / acinner / around class
ia / aainner / around argument
ii/ai · il/alinner / around if-try · loop
Combos to internalize: ciw rename word · di( clear args · ya" yank string · dap delete block · cit edit tag text · vaf select function · cia change argument
Surround (mini.surround): saiw" quote a word · sd" delete quotes · sr"' swap quote style. Swap arguments: sx / sX with next / previous

Entering insert mode

i / ainsert before / after cursor
I / Ainsert at line start / end
o / Oopen line below / above
Escback to normal mode - tap caps (Karabiner) · autosave fires on leaving insert

Search & replace

/foo / ?foosearch forward / backward · n/N next/prev

Visual mode

Registers & macros

"+yyank to system clipboard (this config: clipboard is shared, plain y works too)

Marks & jumps

ma / `aset mark a / jump to it (`` = previous spot)
ctrl+o / ctrl+ijumplist back / forward (BS = back here)
g; / g,previous / next change location

Windows & buffers

Practice ladder

  • 1. hjkl + w/b/e + i/a/o until automatic
  • 2. operators × motions (dw ct) y$), then text objects (ciw di")
  • 3. f/t + ;, %, marks, .-repeat
  • 4. macros, block visual, :g - and vimtutor / term-dojo tutor vim to drill it live

Reference - the why behind the keys

A Keybinding layers - who owns which modifier

The core contract (AGENTS.md): keybindings never overlap across layers. When a key "does nothing", a lower layer consumed it.

macOS globals

  • Karabiner: caps → Ctrl held / Esc tapped
  • Raycast owns cmd+space
  • Hammerspoon binds only hyper chords (cmd+alt+ctrl), which nothing else uses

Ghostty owns cmd+*

  • native tabs/splits/clipboard on cmd
  • VSCode layer translates cmd+p/s/z/a/b into ctrl bytes - plain bytes survive tmux and Herdr, so one shortcut works in every context
  • option = Alt so tmux/nvim meta chords work
  • never binds ctrl-based chords itself

Multiplexers & editor

  • tmux owns ctrl+a only
  • Herdr owns ctrl+b only
  • Neovim owns space (leader) inside its own panes
  • rule: when HERDR_ENV=1, nothing auto-wraps in tmux

D Daily ops - editing the machine

Two speeds of change

  • Instant: anything under files/ is symlinked out-of-store - edit ghostty/tmux/starship/karabiner config, reload the app, done
  • Rebuild: package lists, zsh init, macOS defaults (nix/*.nix) - run rebuild, which the human always drives
  • Homebrew cleanup is zap: any app not declared in nix/host.nix gets uninstalled on the next rebuild - declare everything
  • validate without touching the system: nix flake check --no-build · tests/mac_setup_test.sh
