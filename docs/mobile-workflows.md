# Mobile access (iPad Mini / iPhone)

One tool for the job: Termius (SSH client) over Tailscale (mesh VPN).
A shell on the Mac from mobile covers everything, including driving agents via tmux/Herdr.

History: Paseo (agent-control relay) and Moshi/mosh were both tried in 2026-07 and scrapped in favor of this simpler stack.
Their brew entries were removed from `nix/host.nix`; `cleanup = "zap"` uninstalls them on rebuild.

## Setup

1. `tailscale-app` cask (already declared in `nix/host.nix`); log in on the Mac and on each mobile device with the same tailnet account.
2. Mac: System Settings → General → Sharing → enable Remote Login (SSH).
3. Termius on iPad/iPhone (and Mac, cask `termius`): add host `<you>@<your-host>` (its tailnet name) → `tmux attach` / `herdr` for a remote window into the same sessions.

Keys: per-device, generated by the human (AGENTS.md).
Add each device's public key to the Mac's `~/.ssh/authorized_keys` by hand, labeled with the device name.
Prefer that over Termius's synced-vault keys so private keys never live in a third-party cloud.

Gotcha (2026-07-07): Termius syncs keychain keys across devices by default, so "generated on the device" does not mean "stays on the device" - every device ends up holding every private key, and per-device revocation breaks.
Disable key sync in Termius settings *before* generating the keys; keys generated while sync was on should be regenerated.
To verify isolation: comment out one device's line in `authorized_keys` - reconnecting from that device must fail while the others still work.

## Security model

Tailscale encrypts at the network layer (WireGuard): no open inbound ports, devices authenticate to the tailnet, free personal tier.
Scope is device-level - the whole Mac is reachable from tailnet devices - so keep the tailnet's device list tight.
SSH auth on top is key-only per device.
