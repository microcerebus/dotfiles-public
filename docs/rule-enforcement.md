# Rule enforcement

Pairs each rule in the "Agent operations" section of `files/AGENTS.md` (`~/AGENTS.md`) with what enforces it.
Moved out of `files/AGENTS.md` on 2026-10-14 so it is read on demand instead of loaded into every thread.
The `correct` skill keeps it current: when the owner corrects something a rule already covers, fix it at the highest level that works and update this table.

| Rule | Enforced by |
| --- | --- |
| No em dashes | `write_guard.py` (prose files), `bash_guard.py` (commit messages), `unslop` |
| Real time, context size | `turn_context.py` prints both every turn |
| No containers or VMs | `bash_guard.py` blocks them unless the owner wrote an unexpired `~/.claude/containers-approved-until` |
| Context limits | `turn_context.py`: a nudge on each prompt past 200k; past the 250k hard stop, the stop on each prompt and after main-thread tool calls, repeated once per 5k tokens of growth (never a block); `pre_compact.py` backstop; `pause-safely` skill |
| Handoffs list native workers, never "still hosts" | `write_guard.py` and `bash_guard.py` flag the wording in resume notes and `~/orchestrator`; `pause-safely` and `session-pickup` skills |
| Nothing personal in the public dotfiles mirror | `scripts/public-sync` leak gate, run with the pushed commit's own rules by `.githooks/pre-push` on every push that updates `main` on the dotfiles repo, from any checkout or worktree; only `public-sync --from-origin` publishes, from `origin/main` (`tests/pre_push_test.sh`) |
| Chrome, never Brave | `scripts/chrome-devtools-axi` gates agent callers on active Codex quota state, then checks the Google Chrome Beta executable; Codex computer-use prompt tests name Chrome and exclude Brave |
| Screen-free browser reading, screenshots and WhatsApp Web stay in background agent Chrome tabs | `scripts/agent-chrome-playwright` checks the actual Chrome application and flags, attaches Playwright to 9333, creates a background target and closes only that target; `tests/agent_chrome_playwright_test.cjs` covers ownership, cleanup and refused identity checks; `scripts/axi-session-start` and the axi refusal direct callers here |
| Warn before Codex takes the screen; defer on request and never start after an unanswered warning while the Mac is busy | `scripts/codex-computer-use` runs readiness, shows the 60-second dialog, checks HIDIdleTime for a two-minute idle threshold, defers ten minutes on request, serializes screen ownership and notifies on completion; `tests/codex_screen_gate_test.cjs` covers the decision branches with stubbed dialogs and idle readers; `tests/codex_computer_use_test.mjs` requires the skill and board prompt to use this launcher |
| Agent Chrome, not the owner's own | The quota-gated `chrome-devtools-axi` wrapper still refuses autoConnect and port 9222 unless `CHROME_DEVTOOLS_AXI_MAIN_CHROME=1`; `tests/chrome_devtools_axi_test.cjs` covers both guards |
| Agent Chrome tabs stay behind the owner's windows and are sized per tab | `chrome-devtools-axi` wrapper opens tabs in the background and refuses `resize` |
| HTML tables never split words | `write_guard.py` flags `overflow-wrap: anywhere` and `word-break: break-all` on body or table cells in HTML |
| Agent Chrome has no extensions or sync | launchd flags `--disable-extensions --disable-sync` (`nix/user.nix`); the `chrome-devtools-axi` wrapper refuses an agent Chrome running without them |
| PR bodies explain the change, describe user flows, omit routine CI results and show before/after media for visual changes | `scripts/check-pr-description.mjs` checks body structure and common CI-result patterns; nothing runs it automatically, so the no-mistakes skill instructs agents to run it on the body GitHub holds; `tests/check_pr_description_test.mjs` covers rejected PR #90 inventory/media patterns and command-only flows. Reviewers verify preview identity, observable outcomes, media access and visual fidelity. Product metadata-workflow integration is coordinator-owned. |
| Finished threads are settled regularly | `~/orchestrator/bin/settle-done.mjs` (lifecycle checks before settling) plus `t3_thread_organize`, run on every orchestrator wake, with a native 30-minute maintenance backstop that moves to the successor on handoff |
| Verification runs written user flows through Playwright or Codex computer use (hosted apps: on the exact-head Vercel preview); chrome-devtools-axi only during a confirmed Codex quota fallback the evidence names | `scripts/chrome-devtools-axi` refuses Claude and Codex callers unless `scripts/codex-browser-fallback` reads an unexpired reset time; `tests/codex_browser_fallback_test.cjs` replays the Phase C and WhatsApp commands against a stub; `tests/axi_session_start_test.cjs` prevents the upstream browser advertisement; `tests/verify_agent_board_test.mjs` fails if verify-agent-board lists any driver before Playwright written flows or names chrome-devtools-axi as anything but the fallback; `tests/codex_computer_use_test.mjs` fails if the Codex brief in codex-computer-use (and verify-agent-board's Codex prompt) does not drive Google Chrome Beta on 127.0.0.1:9333 through computer use, activate it first, and keep chrome-devtools-axi out of the driver seat; job-tracker PR #80 tooling test fails if the control-job-tracker skill names chrome-devtools-axi as the default verification driver (coordinator 24); docs only if that test does not land |
| Everything else in "Agent operations" | Rule only, until it repeats |
